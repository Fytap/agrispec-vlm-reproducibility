\section{S4. Matching contracts, proposal selection, and crop exposure}

For truth instance $I$, candidate $C$, all labelled plant pixels $L$, and pixels of role $R$, the offline scorer records
\[
q_I=\frac{|I\cap C|}{|I|},\qquad
q_L=\frac{|C\cap L|}{|C|},\qquad
q_R=\frac{|C\cap R|}{|C\cap L|}.
\]
The primary role-qualified edge requires $q_I\ge0.50$, $q_L\ge0.50$, $q_R\ge0.90$, and a role match. The 27-contract grid crosses $q_I\in\{0.25,0.50,0.75\}$, $q_L\in\{0.25,0.50,0.75\}$, and $q_R\in\{0.50,0.75,0.90\}$.

\section{S6. Merge-aware bounds for the frozen U-Net queue}

Set coverage is the number of distinct truth instances incident to at least one qualified selected candidate. One-to-one support is the maximum matching cardinality. Qualified memberships count all candidate-to-instance edges. Memberships beyond the set union equal total memberships minus distinct covered instances. The merge-capacity gap equals set-covered instances minus matched instances.

\section{S12. Reproducibility boundary and preserved failures}

The release contains frozen configurations, model-acquisition records, environment specifications, training and evaluation source, checkpoint hashes, aggregate and per-image metrics, matching outputs, figure source data, and failure records. Public dataset imagery and weights are acquired from upstream sources. They are not redistributed when upstream terms prohibit redistribution.

The principal environment used Python 3.10.12, PyTorch 2.7.1 with CUDA 12.6, torchvision 0.22.1, and segmentation-models-pytorch 0.5.0. Training used one NVIDIA H200 accelerator per seed. Physical devices 6 and 7 were explicitly assigned. CPU-only aggregation and bootstrap programs read immutable result tables.
